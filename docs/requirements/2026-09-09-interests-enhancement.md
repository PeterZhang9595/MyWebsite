# 整体要求
我希望把兴趣页的前端做的有意思一点，在前端上下一点功夫。

整体是打算使用一种卡牌为对象的组织方式。

第一层主页_index是一系列兴趣种类，然后点入任意一个兴趣之后，可以展示一系列更具体的分类和对应的卡片，每张卡片正面是照片，点击后先放大，再点击则翻面显示文字，再点击则返回最开始的页面原状。

# 设计思路
1. 不再采取和tips,notes一样的页面宽度，而是转为完全占据整个页面的格式（需要你在开发的过程中给我展示一下）

2. 主页是两个部分，上半部分是两张图片，一左一右，这些图片我后面会传，你只需提前先把位置给确定好就行，告诉我后面补充图片的话要在哪里补充。然后我希望这两张图片，点击后先放大到屏幕正中央大约占全屏百分之80，再点击翻面显示介绍文字。

3. 主页的下半部分，借鉴 https://css-tricks.com/ 主页的Popular this month 的部分的前端设计，搞得好看一点。最左边是一张卡片，上面写着“乱七八糟的各种东西”，然后右边是一系列卡片的滑片，全部参考网页前端即可，然后完成这部分之后给我可视化一下效果。

4. 右边的一系列卡片都是可以点入的。暂时先写好运动、随笔、音乐、影视、阅读、生活中的医学。

5. 点击这些卡片中的任意一个之后，进入对应的兴趣子页面。然后整个页面搞得炫酷一点，里面每个卡片按照 C:\WorkSpace\website\docs\design\2026-09-09-interests-card-references.md 进行初步设计（后面还可以设计）每个卡片正面都是图片，点击一次放大，点击两次翻面显示文字。这部分需要你先预排版几个方案给我看看。页面背景看看能不能上网（比较牛逼的css网站）找个不错的彩虹色（粉色）渐变模板。都要在规划的时候提前给我展示一下子。
