# 网站初版设计
## 主页排版设计
我比较想要一个类似于 https://leerob.com/ 的左右排版的主页，整体上来说左边占据的范围更大一些（中间不需要画线之类的硬分割，而是采用留白分割）。然后左边主要是一些学术上的内容，右边是插画视频、music player、近期关注、随机句子这些偏个性化娱乐化的模块。

鼠标拖动的时候应该只移动左边，右边内容始终保持不动，类似于 https://leerob.com/ 。

背景先采用整体白色的设计。

整体包含以下几个部分：
- bio 简介(直接显示)
- 最近关注（直接显示）
- tips文章 （展示所有文章入口）
- notes （提供入口）
- projects （提供入口）
- 随机句子 组件
- 视频插画 组件
- search 组件（基于文字检索）
- music player 组件
- 个人爱好 （提供入口）
- copyright（直接显示）

# 开发要求
1. Github部署是很关键，这一步必须要好好完成并且告诉我最后的网站是什么(.github.io)

2. 你可以根据我的内容设计、astro的框架、以及 https://arthals.ink/ 的源代码去进行src/文件夹结构的设计，要求尽量简洁，每个部分的入口要清晰，方便我后续进行文章的编写。

3. 所有文章都最好以markdown或者MDX文件格式创建。每个文章的字段要至少包含第一次上传的时间戳、最近更改的时间戳、以及其它你觉得有必要的字段（给我提建议，向我申请）。然后文章内主要是字体、代码块、高亮块、数学公式这些具体的需要你给出建议和效果（比如其它人使用的效果展示），并且规划好需要从外部安装的那部分具体的安装位置。

4. 由于这是第一版，所以在各个排版等视觉方面内容都注定要经过大量迭代，请保证你的代码具有充足的可维护和扩展性。

5. 我的叙述和命名有很多模糊的部分，你需要反复和我确认页面的设计。
