# 开发要求
刚刚完成的projects-enhancement有一些方面需要你迭代一下。

1. projects的_index主页，当把光标放在子项目上的时候，不要把边缘变成紫色，而是类似https://arthals.ink/blog把光标放在对应子项目上面时候，要让对应的子项目ui呈现出变灰色的效果，同时字体变灰一点点。

2. 为projects的_index主页设计https://antfu.me/projects 网页前端的散点式界面作为背景。

3. 在每个子项目页面使用绿色、蓝色和红色 的动态波纹组件来包装项目的完成情况；使用的技术栈不要只写名字，想办法从icon网站下载对应的图标，就像github图标一样，可以参考其它的网站中的相关设计。

4. 保证五个类型的项目部分是可以容纳无穷多的子项目的，即前端是可扩展的，而不是仅仅hard-code一个子项目。

5. 每处设计尽可能给我先在聊天里面可视化一下前端效果。
